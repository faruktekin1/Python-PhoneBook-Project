# Python To-Do List Uygulaması

Bu proje, Python öğrenme sürecimde geliştirdiğim, komut satırı üzerinden çalışan basit bir yapılacaklar listesi (To-Do List) uygulamasıdır.

## 🚀 Özellikler

* **Listeleme:** Kaydedilmiş görevleri numaralı bir şekilde listeler.
* **Ekleme:** Listeye yeni görevler ekleyebilirsiniz.
* **Silme:** Tamamlanan veya iptal edilen görevleri listeden silebilirsiniz.
* **Kayıt:** Görevler `gorevler.txt` adlı bir dosyada saklanır, programı kapatsanız bile veriler kaybolmaz.

## 🛠️ Kurulum ve Kullanım

Bu projeyi bilgisayarınızda çalıştırmak için Python'un yüklü olması yeterlidir.

1.  Bu repoyu bilgisayarınıza indirin (veya `tnc_proje.py` dosyasını indirin).
2.  Terminal veya komut satırını açın.
3.  Dosyanın olduğu klasöre gidin ve şu komutu yazın:

```bash
python tnc_proje.py
